# Dr. Spanglish

Landing page institucional responsive basada en la identidad visual aprobada de Dr. Spanglish.

## Archivos

- `index.html`: estructura y contenido.
- `styles.css`: diseño responsive y animaciones.
- `script.js`: menú móvil, animaciones de entrada y testimonios.
- `assets/`: fotografías originales del sitio.

Abre `index.html` con Live Server. Antes de publicar, confirma el teléfono, correo y enlaces sociales finales.
